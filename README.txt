GÜNÜN ÖZETİ — ÜCRETSİZ PWA PROTOTİPİ

Bu sürüm, günlük haber metnini saklar ve Android/Chrome'un Türkçe metin okuma motoruyla seslendirir.
Haberleri kendi başına internetten toplamaz ve ChatGPT otomasyonuna otomatik bağlanmaz.
API anahtarı/ücretli servis kullanmaz.

YAYINLAMA:
1) GitHub'da yeni bir PUBLIC repository oluştur (ör. gunun-ozeti).
2) Bu ZIP içindeki dosyaları kök dizine yükle.
3) Repository > Settings > Pages > Deploy from a branch > main / root > Save.
4) GitHub Pages sana HTTPS adresi verdiğinde Galaxy A54'te Chrome ile aç.
5) Chrome menüsü > Uygulamayı yükle (veya Ana ekrana ekle) > Yükle.

KULLANIM:
1) ChatGPT'deki günlük haber bültenini kopyala.
2) Günün Özeti uygulamasını açıp metni yapıştır ve kaydet.
3) Dinlet'e bas.

SINIRLAMALAR:
- Bu bir PWA prototipidir, klasik APK dosyası değildir. Android Chrome, uygun PWA'yı uygulama gibi yükleyebilir.
- Tarayıcı konuşma sentezinin ekran kapalıyken sürmesi garanti değildir.
- Günlük haber araştırması mevcut ChatGPT otomasyonunda kalır; bu uygulamaya otomatik aktarım henüz yoktur.
